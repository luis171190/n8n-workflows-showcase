# 💬 WhatsApp Booking System

> Sistema de reservas conversacional via WhatsApp con n8n + Evolution API + Google Calendar.

🚧 **En construccion** — workflow en desarrollo. Volve pronto.

## Que hara cuando este listo

- Captara intencion del cliente ("quiero un turno para el martes a la tarde").
- Consultara disponibilidad en **Google Calendar** y propondra slots libres.
- Confirmara con el cliente y creara el evento.
- Disparara recordatorios automaticos 24h y 2h antes del turno via WhatsApp.

## Stack previsto

n8n · Evolution API · Google Calendar · OpenAI · Postgres (memoria conversacional)
